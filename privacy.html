Privacy Policy for Aether

Application: Aether (dev.aether.app) • Effective Date: October 10, 2026
Summary: Aether is a developer AI control plane and coding environment designed with privacy as a foundational principle. We do not operate proprietary tracking servers, we do not sell your personal data, and all sensitive credentials (such as API keys) are stored exclusively on your device using hardware-backed encryption.

1. Information We Collect and Process

Aether is architected to prioritize local-first operation. The application processes the following types of information:

  • AI Credentials and API Keys: API keys you enter (for providers such as OpenAI, Anthropic, Google Gemini, NVIDIA NIM, DeepSeek, Groq, OpenRouter) are encrypted on-device via Android Keystore and EncryptedSharedPreferences. They are never sent to our servers.
  • Prompts, Code, and Conversation History: When you execute prompts or generate code, the data is either processed on-device (via local GGUF models) or dispatched directly to the third-party AI provider you have selected.
  • Local Files and Workspaces: Project files, git repositories, and scratchpads remain within your device's isolated application sandbox.

2. Device Permissions and Usage

Aether requests only permissions strictly necessary for its core functionality:

  • Internet (android.permission.INTERNET): Required to send API requests to user-configured AI providers and download local model weights when initiated by the user.
  • Network State (android.permission.ACCESS_NETWORK_STATE): Used solely to detect connectivity status and manage offline/online fallback queues.
  • Audio / Microphone (android.permission.RECORD_AUDIO): Optional. Used strictly when the user activates voice input for speech-to-text transcription. Audio is never recorded in the background.
  • Camera (android.permission.CAMERA): Optional. Used only when you choose to capture code snippets or images to attach to vision-capable models.

3. Third-Party Services and Data Sharing

Aether connects to external services only at your direct instruction:

  • Third-Party AI Providers: When you send a query using a cloud provider (e.g., NVIDIA NIM, Google Gemini, Anthropic, OpenAI, DeepSeek, Groq, OpenRouter), your prompt data is sent directly over TLS/HTTPS to that provider's official endpoint. Data processing by these providers is governed by their respective privacy policies.
  • No Analytics or Ad Trackers: Aether does not include third-party advertising SDKs, tracking pixels, or commercial telemetry brokers.

4. Data Storage and Security

We implement industry-standard security safeguards to protect your data:

  • Hardware-Backed Encryption: API keys and secrets are protected using AES-256-GCM backed by Android's hardware Keystore.
  • Enforced HTTPS: Cleartext (unencrypted HTTP) network traffic is strictly disabled across the application.
  • Backup Protection: Automated ADB and cloud backup of application secrets is explicitly disabled (allowBackup="false").

5. Data Retention and Deletion

Because your data is stored locally on your device:

  • You can delete any API key, provider configuration, chat session, or workspace directly from within the app at any time.
  • Clearing application storage or uninstalling Aether permanently deletes all local data and credentials from your device.

6. Children's Privacy

Aether is a technical developer tool and is not directed to individuals under the age of 13. We do not knowingly collect personal information from children.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any updates will be reflected with a revised "Effective Date" on this webpage.
